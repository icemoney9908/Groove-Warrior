# 의존성과 검증 범위

## 원본 환경

원본의 `ProjectVersion.txt`와 `Packages/manifest.json`에서 확인한 주요 항목입니다. 전체 패키지 잠금 목록이나 실행 환경 설치 안내를 대체하지 않습니다.

| 항목 | 버전 |
| --- | --- |
| Unity Editor | 6000.3.9f1 |
| Input System | 1.18.0 |
| Cinemachine | 3.1.7 |
| Universal RP | 17.3.0 |
| Timeline | 1.8.10 |
| Unity UI | 2.0.0 |
| Test Framework | 1.6.0 |

## 공개본에 없는 모듈과 에셋

Frontend 소스는 Music & Note 영역의 `KKH.Gameplay`, `KKH.ChartData`, `GrooveWarrior.ChartData`, `GrooveWarrior.Gameplay` 등을 참조합니다. MusicConductor, 노트와 차트 데이터 및 관련 런타임이 필요하며, 담당 모듈의 구현은 이번 공개본에 포함하지 않았습니다.

원본 씬과 프리팹, 입력 액션 설정, ScriptableObject 데이터, 애니메이션, 오디오, 파티클과 그래픽 에셋, 패키지 및 프로젝트 설정도 별도로 필요합니다. 외부 에셋 원본 및 제공 스크립트는 배포하지 않습니다. 외부 에셋의 권리는 각 권리자에게 있습니다.

## 파일 보존과 검증

- C# 및 관련 `.meta`를 원본 경로 그대로 복사하고 SHA-256으로 원본 일치를 확인했습니다.
- 원본 파일의 바이트와 인코딩을 보존했습니다. CP949로 작성된 파일은 편집기에서 인코딩을 선택해 읽을 수 있습니다.
- 문서의 저장소 내부 상대 링크와 허용된 공개 경로를 확인했습니다.
- 공개 후보에 대해 자격 증명 형식의 문자열을 점검했습니다.
- Unity Editor 실행, 컴파일, 빌드, 플레이 테스트는 수행하지 않았습니다.

저장소는 코드 열람용이며 원본 프로젝트를 재구성하거나 테스트 성공을 보장하지 않습니다. 소스 수정, 리팩터링, 기능 추가는 이번 업로드 범위에 포함되지 않습니다.
